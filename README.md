## Featured Projects

**[Semantic Segmentation Robustness Under Image Degradation](https://github.com/vamsikumaryerasani/Assessment-of-Semantic-Segmentation-Robustness-Under-Image-Degradation)**
Evaluated DDRNet-23, SCTNet-B-Seg75, and SCTNet-B-Seg100 for real-time semantic segmentation on railway scenes, benchmarking robustness under fog, rain, snow, and illumination changes across RailSem19 and a simulated dSPACE dataset. DDRNet-23 reached 90.38% mIoU on RailSem19.

**[Vehicle Safety System](https://github.com/vamsikumaryerasani/Vehicle-Safety-system)**
Embedded C++ system for monitoring parked vehicles — motion, temperature, smoke, and air-quality sensors with real-time Telegram alerting.
